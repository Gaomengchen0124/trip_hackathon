# 本地道路数据

shanghai-streets.json 来自 OpenStreetMap API，提取日期 2026-10-07。

来源：https://api.openstreetmap.org/api/0.6/map?bbox=121.46,31.22,121.48,31.24

这是上述范围及与其相交道路的 GeoJSON 提取数据，保留 WGS84 坐标、名称和水道标签。
仅用于网络不可用时显示人民广场周边道路，不能代替完整上海底图，也不提供导航。
没有下载、缓存或分发 OpenStreetMap 的离线瓦片包。
未来增加北京、大理、厦门路线时，需要另外补充对应范围的本地矢量数据。
