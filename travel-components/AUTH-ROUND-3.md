# 账号体系 · 第三轮

完成共用登录拦截与操作恢复。访客触发收藏时打开演示登录，登录完成且弹窗关闭后执行原操作；取消登录不执行。等待期间重复点击只处理一次，页面离开或组件卸载时可取消待执行操作。

## 可运行预览

从项目根目录运行静态服务，访问 http://127.0.0.1:8000/demo.html。

首页 → 繁花·上海 → 选择一个点位 → 收藏路线 → 邮箱／手机号 → 获取演示验证码 → 输入 123456 → 登录。收藏自动完成，日期和所选点位保留。关闭登录时不执行收藏，可再次触发。

收藏仅保存在当前页面内存，刷新或退出后清空，不是持久收藏。评论尚未实现，本轮没有宣称验证评论草稿恢复。当前账号仍是演示身份，真实服务端认证、收藏隔离与保存留待后续轮次。

## Vue 接入

- 新增 src/auth/login-gate.mjs：纯逻辑拦截器，getUser、requestLogin 由使用方提供。
- 更新 src/auth/login-dialog.mjs：新增 requestDemoLogin，关闭弹窗时返回最终登录结果。
- 新增 src/components/FavoriteButton.vue：景点收藏流程演示，组件卸载取消待执行操作。
- 更新 src/views/DetailView.vue：将收藏按钮接在景点内容上方，使用 poiId 作为组件 key。

在前两轮基础上合并以上四个文件。wish-feature 内同步了共用 auth 模块；若主工程使用许愿首页，依然使用 travel-components 的 FavoriteButton 和详情页接线，合并为同一个 src 目录。旧 changes.patch / manifest.json 不含本轮变更。

业务使用方式：创建 gate，调用 gate.run(() => 原操作)，在离开页面或组件卸载时调用 gate.cancel()。传入回调前固定本次操作的对象与内容，避免登录后误用新的路由或输入。

## 验证结果

自动测试：auth-session、login-form、login-gate 和 travel-ui 共 17 项通过。覆盖登录后继续、取消登录、重复点击、离开页面取消、动作异常后重试及原有登录校验。
