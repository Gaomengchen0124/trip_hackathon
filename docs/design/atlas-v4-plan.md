# 第四版：古典远行图鉴 / The Atlas of Stories

## 统一方向

用户希望大幅提升构图、布局和连续交互，而不是只换颜色。保持已有金色品牌、米白纸张、淡铅笔与手绘海豚，使用古典图鉴式的大版面照片、非对称留白、地图网格、页边注释、少量暖墨色对比区。避免新增彩色主题、重复功能入口卡、厚重圆角卡片堆叠。

叙事节奏：序章（远方）→ 首页（寻找故事）→ 路线（走进作品）→ 规划（连起坐标）→ 行程（写成旅行）→ 许愿（未写完的一页）。

## 分工及文件边界

1. 主智能体：App.vue、OpeningSequence.vue、OpeningLandscape.vue、opening-sequence.css、全站页面转场、公共背景 / tokens、资产、协调及最终整合。保留序章占位，实现从首页原生向上滚回序章，不重置或吞掉已滚过的距离。
2. 首页智能体：HomeView.vue、TravelMasthead.vue、IpWall.vue、RouteCard.vue、首页专属 CSS、新的海豚陪伴组件。删除 wish-entry / recommend-entry 两个卡片；保留搜索 / 空结果许愿、现有线路与导航链接。首页用编辑式布局与更有层次的照片编排。海豚置于页边书签 / 同行者位置，可触发原有问候，并可使用既有导航路由。
3. 内页智能体：StoryChapter.vue、StoryFooter.vue、SiteNavigation.vue、单独 atlas-pages.css，必要时仅调整公开 View 的展示模板 / class。不改业务脚本、数据、接口。路线页、推荐页、目录、规划、结果和许愿的布局层级必须明显提升。
4. 验证智能体：浏览器测试与审阅，更新双向序章回归，验证搜索、选点、推荐、许愿、行程保存 / 恢复等原有业务。实现文件由对应负责人修复，测试负责人不改业务代码。

## 视觉协议

- 背景 #f6f1e7 / #fffdf7，墨 #3f382c，金 #aa8650 / #c4a464，少量暖深褐 #3c3428；不引入蓝 / 绿主题。
- 大标题使用现有宋体 / Georgia，正文仍保持易读。留白与印刷式分栏优先，不用过多口号填充。
- 所有图片沿用真实现有路线数据，手绘装饰不得伪装成目的地实拍。
- 共用坐标刻线、椭圆印章、双细线、渐隐的手绘线稿。可用原有 world-panorama-v1.png 与 atlas-pencil-v2.webp。主智能体可能补充 public/img/opening/atlas-portal-v4.webp，其他模块不依赖该文件才可独立工作。
- 公共 scope 为 .story-content.public-story；避免修改表单、地图、弹窗功能。禁用 / focus / loading / error 状态保持。
- 动画主轴是原生滚动与纸页翻阅；全站保留现有金色笔迹光标，不增加泡泡。
- 移动端、键盘、减少动态效果、图片失败和深链接要可用。
