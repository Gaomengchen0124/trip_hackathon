# 智能推荐模块范围与规则

版本：1.0。日期：2026-10-16。适用项目：Gaomengchen0124/trip_hackathon。

本文记录产品负责人已确认的功能范围，供开发助手、推荐模块、规划模块和数据库同学共同使用。实现与启动见[开发和配置说明](implementation.md)。规划交接仅沿用现有 lineId 跳转。

## 目标与职责

在现有“我的圣地巡礼”项目中，帮助用户根据内容兴趣发现作品及已有巡礼路线，再进入已有路线介绍与规划流程。设计支持持续扩充 IP，不将当前目录数量写死在界面、提示词或算法中。

- 推荐模块：首页“智能推荐”入口；两种推荐模式；首次登录后可跳过的内容兴趣选择；兴趣修改；路线推荐、解释与反馈；DeepSeek 服务端接入；选定路线后的信息交接。
- 规划模块：路线内活动偏好、景点预选、手动调整、必去点、排程、地图、时间与取舍。路线介绍页由对应页面负责人维护，推荐模块不自行修改其内容。
- 数据库模块：标签、用户画像、作品、路线、地点及关联关系、数据查询与持久化；具体表结构和服务接口待共同确认。
- 推荐卡片可展示资料中的代表景点，作为路线亮点，不代表已勾选、已排程或保证可游览。

## 两种推荐模式

### 围绕喜欢的作品去旅行 by_work

起点是用户明确喜欢的作品或人物。先识别作品、版本与人物关联，再在对应已收录路线中根据目的地等条件推荐。人物不明确时澄清，不凭同名映射。

只剩一条适合的路线就展示一条；没有符合条件的路线时说明缺口。相似作品路线由用户主动选择查看，不能悄悄替换指定作品。未收录作品可接入现有巡礼许愿入口。

### 帮我发现下一次旅行 discover

起点是内容兴趣、目的地范围或一句话需求。可跨作品和城市推荐，说明“为什么你可能喜欢”。建议展示最多三条路线，控制重复 IP；不足三条不凑数。支持本次反馈“更想看这类”“对这类不感兴趣”。

切换模式保留目的地与未提交兴趣描述；作品限定发生变化时在界面明确显示，不能隐藏改变。

## 用户画像与输入

首次登录成功后提供可跳过的内容兴趣引导；中途登录后回到原页面并保留选择。游客可使用推荐。跳过后不反复阻拦，个人中心提供修改入口。

长期画像包含：内容载体（小说、影视剧、电影、动漫、文学散文等）、故事题材（科幻、悬疑、奇幻、历史、都市、青春等）、喜欢的作品或人物。枚举是候选方案，最终使用数据库统一字典和稳定标签 ID。作品版本须区分，不能把原著地点自动解释为改编作品取景地。

本次输入可包含：模式、作品／人物或兴趣、目的地范围、自由文本；日期、每天时长统一在规划页填写。用户可以只填写部分信息。优先级为用户本次明确选择高于长期画像，高于 AI 推测。本次反馈默认不改长期画像，用户主动选择保存后才更新。

Citywalk、购物、美食、咖啡、步行量、远郊接受度和必去点等由规划模块提供交互。用户在推荐自由文本中主动提到这些要求时，提示在规划页设置；推荐模块不另建相同表单，也不据此承诺已经完成排程。

## 推荐依据与数据约束

- 沿用 ipId、lineId、poiId，不自行重新编号。新概念字段如作品版本、地点实体 ID 须与数据库同学确认。
- 同一地点可关联多个作品；基础位置数据与作品关联说明分别维护，沿用现有 ID 的兼容关系。
- 缺失信息是未知，不等于支持或不支持。只有可靠数据支持时，才判断路线满足某项条件。
- 用户明确限定的目的地与排除条件应被尊重；冲突时解释并请用户选择，不自动放宽。
- 原著提及、影视取景、官方主题体验、主题延伸是不同关联，不互相冒充。
- 不编造作品、地点、引文、坐标、开放信息或实时票价。不以无校准的百分比冒充匹配准确率。
- 题材、氛围等软偏好可用于排序，但应解释未满足的偏好；不可把 AI 解析直接当作用户确认。

## DeepSeek 的职责

服务端提供当前有效候选摘要，由模型理解需求、排序并给出基于资料的理由。服务端校验输出结构、候选 ID、字段与硬条件，展示名称和图片来自项目数据。模型不决定实际行程时间和点位安排。

密钥由服务端环境变量提供，不使用 VITE_ 前缀，不进入浏览器、Git、日志或交接材料。接入时验证账号可用模型；模型名、超时和调用上限可配置。开发 skill 不会自动成为 DeepSeek API 的运行时上下文，后端须显式组织请求。

模型失败时保留用户输入，可展示标为“基础推荐”的规则结果，不伪装成本次 AI 成功结果。本次推荐条件和结果保存在当前标签页，恢复期限为两小时，按账号隔离；不新增规划草稿。

## 验收重点

作品模式尊重指定作品；灵感模式可跨作品发现；不同输入会改变排序和解释；游客与跳过画像可用；已知与未知状态清楚；无候选有可操作反馈；选定路线能进入现有流程；用户输入来源明确且原行程不被意外覆盖；扩充有效数据后不需要修改硬编码目录。
